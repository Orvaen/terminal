# Logo

[← Retour à l'accueil](../README.md)

Terminal est un logiciel Arkerion. Son logo suit l'identité d'Arkerion : même grille, mêmes arrondis,
noir et blanc uniquement, et le nom composé en Arkerion Sans.

## Le symbole Invite

Un écran avec l'arrondi signature d'Arkerion en haut à droite. L'invite `>_` y est creusée en modules :
trois carrés en chevron, puis le curseur.

## Fichiers

Dans [`docs/brand`](brand) :

| Fichier | Usage |
|---|---|
| `terminal-logo-noir.svg`, `terminal-logo-blanc.svg` | Logo complet |
| `terminal-symbole-noir.svg`, `terminal-symbole-blanc.svg` | Symbole seul |
| `terminal-nom-noir.svg`, `terminal-nom-blanc.svg` | Nom seul |
| `terminal-avatar-noir.svg`, `terminal-avatar-noir.png` | Avatar carré (1024 px) |
| `terminal.ico` | Icône Windows |
| `terminal-partage.png` | Carte de partage GitHub (1280 × 640) |

Le noir sert sur fond clair, le blanc sur fond sombre. Pas de couleur, pas de déformation, pas de rotation.

Tous ces fichiers sont générés par [`build.py`](brand/build.py), voir [Développement](developpement.md#logo).
